# 非理想因素（sim/artifacts.py）

> 对应代码：`sim/artifacts.py`。v1 实现三类：白噪声、呼吸调制、工频开关（默认关），外加采样后的量化。

## 1. 原理与动机

仿真器要回答的问题不是"理想算法多好"，而是"算法在真实恶化下多稳"。各因素都有明确测试目的：

| 因素 | 模拟对象 | 测试目的 |
|---|---|---|
| 白高斯噪声 | 传感器电噪声 | 下限健壮性；部分泄漏进 0.5–8 Hz 通带 |
| 呼吸调制 | 呼吸引起的基线波动 | 骑在 0.5 Hz 高通截止边界，**专门考验滤波器设计** |
| 量化（LSB=0.1） | ADC 分辨率（E1 规格） | 峰检测/包络对台阶的健壮性 |
| 工频（默认关） | 电源耦合 | 50 Hz 在 80 Hz 下混叠至 30 Hz（带外），留开关备考 |

**为什么在 1000 Hz 密集网格上加噪**：白噪在密集网格上生成、抽样到 80 Hz 时高频成分自然混叠回带内——这与真实 ADC 前端的混叠行为一致，比"直接在 80 Hz 网格加噪"更诚实。

## 2. 数学模型

$$p_{noise}(t) = p_{clean}(t) + \sigma_n\, \mathcal{N}(0,1)$$

$$p_{breath}(t) = p_{noise}(t) + a_b \sin(2\pi f_b t + \phi_0),\quad \phi_0\sim\mathcal{U}(0,2\pi)$$

$$p_{mains}(t) = p(t) + a_m \sin(2\pi f_m t)\quad (\text{默认关闭})$$

$$p_{raw} = \mathrm{round}(p / LSB)\cdot LSB\quad(\text{在 80 Hz 输出网格上，抽样之后})$$

## 3. 参数表（`ArtifactParams`）

| 参数 | 默认 | 说明 |
|---|---|---|
| noise_sigma | 0.02 mmHg | 温和强度 |
| breathing_amp / hz | 0.5 mmHg / 0.25 Hz（15 次/分） | 骑 0.5 Hz 边界 |
| mains_on / amp / hz | False / 0.2 mmHg / 50 Hz | 默认关闭 |

## 4. 实现映射

| 函数 | 签名 | 职责 |
|---|---|---|
| `add_noise` | `(p, sigma, rng)` | 加性白高斯 |
| `add_breathing` | `(p, t, amp, hz, rng)` | 正弦调制（初相随机） |
| `add_mains` | `(p, t, amp, hz)` | 工频（默认关） |
| `quantize` | `(p, lsb)` | LSB 舍入（采样后执行） |
| `apply_artifacts` | `(p_clean, t, params, rng_noise, rng_breath)` | 固定顺序：噪声→呼吸→(工频) |

## 5. 已识别但未建模（后续迭代）

| 因素 | 原计划模型 | 补做时机 |
|---|---|---|
| 运动伪影 | 随机突发宽带噪声：1–3 段 × 0.5–2 s，σ=0.3–1 mmHg | W5 管线 QC 判废路径需要测试输入时 |
| 泵阀瞬态 | 停泵时刻尖峰 + SETTLE 段指数衰减（τ≈0.3 s） | 拿到面包板首采数据后按实测补 |

**已知测试缺口**：QC 的运动判废路径暂无仿真输入覆盖（`apply_artifacts` 的顺序契约已预留注入位）；待伪影建模后补测。

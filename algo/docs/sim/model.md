# 信号模型（sim/model.py）

> 对应代码：`sim/model.py`｜本文含**统一符号表**；其余文档引用本文符号，不重复定义。

## 1. 原理：袖带里读到什么

压力传感器读到的是袖带内空气总压，为三个成分的线性叠加：

$$p_{raw}(t) = P_{cuff}(t) + \underbrace{A(P_{cuff})\cdot w(\varphi)}_{\text{振荡波}} + n(t)$$

- **DC 分量** $P_{cuff}(t)$：0–240 mmHg 慢变斜坡（充气→静置→放气→快排），是"载波"。
- **AC 分量（振荡波）**：逐搏压力波动，幅度约 1–3 mmHg（约为 DC 的 1/1000）。
- $n(t)$：非理想因素，见 [artifacts.md](artifacts.md)。

### 1.1 振荡的来源：动脉顺应性 S 曲线

袖带压 $P_c$ 压迫肱动脉；动脉内压 $P_a(t)$ 每搏在 $[DBP, SBP]$ 间搏动。**跨壁压**

$$P_t = P_a - P_c$$

决定动脉被压扁的程度。动脉血容积 $V(P_t)$ 由顺应性 $C(P_t)=\mathrm{d}V/\mathrm{d}P_t$ 积分而来，整体呈 S 形：$P_t$ 很负时动脉完全压闭（容积趋 0）；峰位附近管壁最"软"（容积对压力最敏感）；$P_t$ 很正时动脉完全张开绷紧（容积饱和）。本模型 $C(P_t)$ 为**非对称高斯**（峰位 $\mu<0$、压闭侧衰减快、扩张侧衰减慢，见 §2.1）。

一搏之内 $P_a$ 从 DBP 扫到 SBP，动脉容积变化为**准静态积分**：

$$\Delta V(P_c) = \int_{DBP-P_c}^{SBP-P_c} C(P_t)\,dP_t = V(SBP-P_c) - V(DBP-P_c)$$

容积变化经袖带气路转换为该搏的压力波动：

$$A(P_c) = \frac{\Delta V(P_c)}{k_{cuff}}$$

### 1.2 放气扫描 = 积分窗滑过 S 曲线

放气过程中 $P_c$ 从高于 SBP 降到低于 DBP，"积分窗" $[DBP-P_c,\ SBP-P_c]$ 随之滑过 S 曲线：

| $P_c$ 区间 | 积分窗位置 | 振荡行为 |
|---|---|---|
| $P_c > SBP$ | 整窗在压闭饱和区 | 很小（动脉基本闭合） |
| $SBP > P_c > DBP$ | 窗骑跨陡峭段 | 先增后减（部分开放） |
| $P_c < DBP$ | 整窗在张开饱和区 | 小（全程开放） |

一串搏动的幅度连成**钟形包络**；积分窗骑跨 S 曲线拐点时振荡最大，故**包络峰值 ≈ MAP**。

数值例（normal：SBP=120, DBP=80，形状参数=默认锚定值，$k_{cuff}=20$）：

| $P_c$ | 积分窗 | $A(P_c)$ / mmHg |
|---|---|---|
| 150 | [−70, −30] | 0.000 |
| 130 | [−50, −10] | 0.388 |
| 120 | [−40, 0] | 0.958（= 0.500×$A_{max}$，SBP 锚点） |
| **96.4** | **[−16.4, +23.6]** | **1.917（峰值，$k=0.41$）** |
| 80 | [0, +40] | 1.342（= 0.700×$A_{max}$，DBP 锚点） |
| 70 | [+10, +50] | 0.949 |
| 60 | [+20, +60] | 0.612 |

注意两侧尾部不对称：DBP 侧（60 mmHg 处仍 0.61）明显长于 SBP 侧（150 mmHg 处≈0）——由「压闭侧衰减快、扩张侧衰减慢」的形状假设决定（§5.1）。

### 1.3 频域视角（为什么带通 0.5–8 Hz）

AC 分量在频域分三个区段，这正是带通边界的选择依据：

| 频段 | 内容 | 处置 |
|---|---|---|
| < 0.5 Hz | 呼吸调制（0.2–0.33 Hz）、残余 DC 漂移 | 高通滤除 |
| 0.67–3 Hz | 脉搏基频（HR 40–180 bpm），谐波延伸至 ~8 Hz | **保留 = 信号** |
| > 8 Hz | 传感器白噪、量化噪声 | 低通滤除 |

`scripts/plot_spectrum.py` 可对任一场景生成频域分析图（MAP 稳态窗频谱＋全放气段频谱图＋高低压 PSD 对比＋噪声底标注）：仿真中脉搏谐波呈清晰梳状谱（k×基频），高压段仅剩噪声底——带通设计的实证依据。频域 HR 估计与真值一致（normal 70.0/70，tachycardia 180/180）。

## 2. 数学模型

### 2.1 顺应性曲线与逐搏幅度

顺应性为非对称高斯（峰位 $\mu$，两侧宽度 $\sigma_n/\sigma_p$），血容积为其解析积分（erf 分片式）：

$$C(P_t) = C_0\exp\!\left(-\frac{(P_t-\mu)^2}{2\,\sigma(P_t)^2}\right),\qquad
\sigma(P_t)=\begin{cases}\sigma_n, & P_t<\mu\\ \sigma_p, & P_t\ge\mu\end{cases}$$

$$A(P_c) = \frac{V(SBP-P_c) - V(DBP-P_c)}{k_{cuff}},\qquad
V(P_t)=\int_{-\infty}^{P_t} C\,dP_t\ \text{（erf 解析式，见 `volume()`）}$$

- 分片点取在峰位 $\mu$：两侧在峰处的取值与斜率均相等（$C^1$ 光滑，无折变；$V$ 为 $C^2$）。
- 三个无量纲形状参数 $(\sigma_n/PP,\ \sigma_p/PP,\ \mu/PP)$ 经 `scripts/fit_shape.py` 对锚点 $(r_s,r_d,k)=(0.50,0.70,0.41)$ 求解并按脉压缩放 → 跨血压**自相似**（§5.1）。
- 默认参数下 $A_{max}\approx 1.92$ mmHg（1–3 规格内），包络峰值 $P_c^{*}\approx 0.41\,SBP+0.59\,DBP$。

### 2.2 脉搏波形（双高斯解析近似）

一搏内相位 $\varphi\in[0,1)$：

$$w(\varphi) = e^{-\left(\frac{\varphi-0.15}{0.08}\right)^2} + 0.4\,e^{-\left(\frac{\varphi-0.35}{0.10}\right)^2}$$

主峰（收缩期，μ=0.15）＋重搏波（μ=0.35）。选它的理由：光滑、无尖点、参数物理意义直白；谐波自然落在 0.5–8 Hz 带通内。真实数据到位后可换成实测平均波形，接口不变。

### 2.3 DC 四段斜坡（与测量流程 §1.2 对应）

| 段 | 行为 | 时长（normal） |
|---|---|---|
| INFLATE | 0 → 180 mmHg @ 10 mmHg/s | 18.0 s |
| SETTLE | 保持 180 mmHg（丢弃停泵瞬态） | 1.0 s |
| DEFLATE | 180 → 40 mmHg @ 3 mmHg/s（自然漏气） | 46.7 s |
| DUMP | 40 → 0 mmHg @ 80 mmHg/s（快排） | 0.5 s |

### 2.4 搏动时刻序列

$$RR_k = \frac{60}{HR}\cdot\max\left(1 + j\cdot \mathcal{N}(0,1),\ 0.25\right)$$

$j$ = `beat_jitter`（0 = 规则节律；房颤场景 0.2）。搏动起点 $t_0=0$。

### 2.5 合成方程（密集网格）

$$p_{clean}(t) = P_{cuff}(t) + \sum_k \mathbb{1}_{[t_k,\,t_{k+1})}(t)\, A\big(P_{cuff}(t)\big)\cdot w\left(\frac{t-t_k}{RR_k}\right)$$

- 幅度按**搏内调制**：$A(P_{cuff}(t))$ 随袖带压逐样本变化（标准准静态 AM 模型），**不设人为取幅点**——真实设备对振幅-压力的配对只能是同刻采样（GCY/agata 语义，见 §5.2 修正记录）。
- 全程合成：充气段也有振荡（真实设备亦如此），但管线只在 DEFLATE 段做正式分析。

### 2.6 统一符号表

| 符号 | 含义 | 单位 |
|---|---|---|
| $P_a,\ P_c,\ P_t$ | 动脉内压 / 袖带压 / 跨壁压 | mmHg |
| $P_{cuff}(t)$ | DC 分量（袖带压基线） | mmHg |
| $V(P_t)$ | 动脉血容积（顺应性积分） | a.u. |
| $C(P_t),\ C_0$ | 动脉顺应性曲线 / 峰值 | a.u./mmHg |
| $\sigma_n,\ \sigma_p$ | 顺应性负/正侧高斯宽度（默认 0.058 / 0.781×脉压） | mmHg |
| $\mu$ | 顺应性峰相对 $P_t{=}0$ 的偏移（默认 −0.340×脉压） | mmHg |
| $v_{max},\ k_{cuff}$ | S 曲线幅值 / 气路转换系数 | a.u., a.u./mmHg |
| $A(P_c)$ | 逐搏振荡幅度（包络） | mmHg |
| $w(\varphi)$ | 归一化脉搏波形 | – |
| $RR$ | 搏动间期 | s |

## 5. 参数锚定、已知简化与搁置项

### 5.1 形状锚定（与信号处理端对齐，2026-10-04）

管线用固定比率 0.50/0.70 反推血压、以包络峰为 MAP（口径纪律）。仿真包络若与该规则不自洽，"正确实现的管线"也会在真值上显示系统假误差（曾达 +2~+7.5 mmHg、一边倒）。修正方向不是改管线常数，而是把仿真形状**锚定**到管线常数：

| 锚点 | 目标 | 来源 |
|---|---|---|
| $r_s = A(SBP)/A_{max}$ | 0.50 | `bp.params.ratio_sbp` |
| $r_d = A(DBP)/A_{max}$ | 0.70 | `bp.params.ratio_dbp` |
| $k = (P_c^{*}-DBP)/PP$ | 0.41 | Dhamotharan 2023（N=122 实测） |

`scripts/fit_shape.py` 用 fsolve 对参考个体 (120/80) 求解 3 个无量纲参数：

| 参数 | 解（采用 R0） |
|---|---|
| $\sigma_n/PP$ | 0.058428 |
| $\sigma_p/PP$ | 0.780582 |
| $\mu/PP$ | −0.340360 |

自检（脚本内置输出）：锚点精确命中；参数按脉压缩放后 (160/100)、(90/60)、(150/70) 的比率与 $k$ 完全不变；$C$ 在峰位两侧连续、斜率相等。对齐效果：管线 8 场景 MAE 从 3.0/4.2 降到 **0.4/0.9 mmHg**（docs/pipeline/pipeline.md §3）。

**可辨识性说明（搁置项）**：锚点方程在该族中有 **3 组根**（`scripts/fit_shape.py` 多起点求解 + 解空间扫描复核）：

| 根 | σₙ/PP | σₚ/PP | μ/PP | 形态 |
|---|---|---|---|---|
| **R0（采用）** | 0.0584 | 0.7806 | −0.3404 | 塌陷侧陡、扩张侧缓，峰偏压闭侧 |
| R1 | 0.2960 | 0.4480 | −0.0121 | 两侧较均衡，峰近零 |
| R2（弃） | 0.7215 | 0.0473 | +0.5285 | 生理方向反转（塌陷侧缓于扩张侧） |

三组解命中同样的三个锚点，差异只在未锚定的包络尾部区域。采用 R0 的依据：符合「压闭侧衰减快、扩张侧衰减慢」的既有生理方向（B+μ 讨论，Raamat 2013 背景）。真实数据标定后可重新裁决（见 §5.2）。

### 5.2 已知简化与搁置项

1. **单一个体形状**：默认参数 = 人群锚点中心的确定个体；无个体间形状散布。
2. **准静态假设**：不模拟搏内的"压扁→开启"动态；波形形状不随 $P_c$ 改变（真实接近 SBP 时有畸变）。
3. **搏内调制（2026-10-01 修正）**：合成按 $A(P_{cuff}(t))$ 逐样本缩放；原"搏动中点单点取幅"已废除——该时刻真实设备不可观测（流式固件只做同刻采样），曾给管线验证引入 $0.5\cdot RR\cdot$ 放速 $\approx +0.7\sim+1.7$ mmHg 的约定差。残余：波形形状仍不随 $P_c$ 变化（并入第 2 条）。
4. **形状参数 ∝ 脉压（自相似，2026-10-04）**：各场景 $A_{max}$ 恒为 ≈1.92 mmHg；真实中幅度与形状随脉压、臂围、耦合变化。与文献"层 3"（比率随血压水平漂移，Geddes：SBP 比率 0.57→0.45）冲突，属自觉搁置。
5. **无气路动力学**：传感器读数 = 袖带压，无气管延迟/衰减。
6. 脉搏波为解析近似（双高斯），非实测模板。

**搁置项清单（暂不引入；用户指示记录，2026-10-04 立）**：

| 搁置项 | 内容 | 触发条件 |
|---|---|---|

| 层 3 状态依赖 | 比率随血压水平/动脉硬度漂移（Geddes；Babbs 2012），替代"形状∝脉压"假设 | 真实数据标定后 |
| μ 人群散布 | μ 无文献分布值（默认值来自锚点反解）；若加分布需先定小散布（±2 mmHg 量级）并记录来源 | 随"人群形状分布" |

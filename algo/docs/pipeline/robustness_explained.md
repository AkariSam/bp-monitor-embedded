# 参数扫描实验结果讲解（通俗版）

> 本文是 [robustness.md](robustness.md) 的通俗版：同一批实验、同一批数据，
> 写给不需要了解算法内部细节的读者（队友、汇报、评审）。
> 技术口径、复现命令与完整表格见 robustness.md；本文只保留结论和"为什么"。

## 1. 这四组实验在问什么

四组实验共跑了约 2600 次完整的「充气 → 放气 → 出结果」流程。
做法都一样：每次只改一个条件，其余保持不变，与标准情况对比。

| 实验 | 一句话概括 |
|---|---|
| 一、算法内部参数 | 算法里 10 个可调的"旋钮"，哪些碰不得？ |
| 二、干扰压力测试 | 噪声、呼吸、心跳不齐、放气快慢——干扰到什么程度会测不准？ |
| 三、比率换算验证 | "包络一半高度找收缩压、七成高度找舒张压"的换算，和文献对不对得上？ |
| 四、生理参数边界 | 每个人的血管形状都不一样，差异会带来多大的误差？ |

## 2. 实验一：算法内部的旋钮，哪些碰不得

把 10 个参数逐个改动（每次只动一个），看测出的血压差多少、会不会把合格测量误判成废数据。

**7 个参数怎么调都没影响**（比如估计噪声用的分块大小、判断心跳的参考窗口长度等）。
这些参数当初怎么定的无所谓，以后也不用再管。

**2 个参数动大了会出事：**

- **心跳幅度门槛**（默认 0.5 mmHg）：它是判断"这算不算一次心跳"的最低幅度。
  调大到 0.75 就开始误判，调到 1.0 时 24 次测量误判了 19 次。
  方向明确：只能调小、不能调大。
- **包络平滑窗口**（默认前后各看 3 个点）：完全不平滑时，舒张压读数会偏近 3 mmHg；
  平滑过头（5 个点）时，心跳慢的人因为总心跳数太少，会被误判成废数据。
  默认值 3 正好在安全区间的正中间。

**1 个参数名义上要小心、实测完全无感**：峰显著度比例从 0.10 调到 0.50，
结果一模一样——因为心跳峰远比噪声峰大，这个门槛根本碰不到任何东西。

## 3. 实验二：干扰压力测试

往信号里逐步加干扰，看误差什么时候明显变大。

**白噪声（随机抖动）——没有崩溃点，只会慢慢变差：**

| 噪声强度（σ，mmHg） | 0.02 | 0.05 | 0.1 | 0.2 | 0.4 |
|---|---|---|---|---|---|
| 平均误差（收缩压 / 舒张压，mmHg） | 0.6 / 0.9 | 0.9 / 1.0 | 1.4 / 1.5 | 2.6 / 2.4 | 4.8 / 4.6 |
| 误判成废数据的比例 | 0 | 0 | 0 | 0 | 0 |

噪声加到 0.4 mmHg（超过心跳信号本身幅度的两成）也没有出现"突然测不出来"的悬崖，
误差只是平滑地变大。原因是：白噪声不改变心跳的位置和包络的整体形状，只是让每个
采样点上下抖动；而判定用的是"高度的比例"，对这类均匀抖动天生不敏感。

**但这是一把双刃剑**：噪声很大时，算法不会报"测不出来"，而是照常给出一个已经
偏差的读数——检查程序识别不了"噪声大但形状完好"的数据。另外，真实世界的运动
伪影并不是白噪声，这个结论不覆盖它（见第 7 节）。

**其他干扰：**

- **呼吸**（袖带压力随呼吸缓慢起伏）：幅度 1 mmHg 以内安全；到 2 mmHg 时正好
  压在滤波器的边界频率上，收缩压会被拖高约 10 mmHg，还有约四分之一被判废。
- **心跳不齐**（心跳间隔随机抖动 ±30%）：完全扛得住——心率是用所有间隔的
  中位数算的，个别早搏拉不动中位数。
- **50 Hz 工频干扰**：几乎无影响。
- **最坏情况全部叠加**（噪声 0.2 ＋ 呼吸 1.0 ＋ 放气 5 mmHg/s ＋ 抖动 0.2）：
  误差约 6 / 4 mmHg，仍在接近商用设备合格线的水平。

## 4. 实验三：比率换算验证

比率法就是"在包络一半的高度划线找收缩压、七成高度划线找舒张压"。这组实验验证两件事：

- **零点**：仿真里形状的标准就是按 0.50 / 0.70 定的，理论上最好的比率就该是这两个数。
  实测最优值是 0.5105 / 0.7096，只差约 0.01——这是"每次心跳只能采到一个包络点"的
  采样精度极限，不是实现错误。
- **斜率**：比率每偏 0.1，收缩压读数就差约 4 mmHg。文献里说比率差 0.2 对应约 8 mmHg
  误差——完全吻合。说明实现正确，而且这个换算比例可以用来预估真机上个体差异有多大。

## 5. 实验四：生理参数边界

真实人群里每个人的血管形状都不一样，仿真器只有一个"标准人"。这组实验人为改动
形状参数，相当于预演"人和人之间的差异"会造成多大误差。

- **形状差异对舒张压的影响远大于收缩压**：形状参数偏 40%，舒张压误差能到 8–14 mmHg，
  收缩压只有 2–4 mmHg。真机上舒张压更难测准，与文献一致。
- **信号太弱的底线**：心跳在袖带里引起的振荡幅度低于约 1.3 mmHg 时开始测不出来
  （幅度门槛把微弱的峰全滤掉了）。设计值约 2 mmHg，余量只有 1.4 倍——
  胖手臂、袖带缠松的人是风险人群。
- **放气太快 ＋ 心跳太慢是危险组合**：40 次/分的心率配 5 mmHg/s 的放气，
  每次心跳之间压力就掉 7.5 mmHg，整段放气只采到 9–10 个心跳点，直接判废。
  放气速率要控制在 2–4 mmHg/s。
- **预充余量**：充气超过收缩压 10 mmHg 是最低线；固件现在用的"上次收缩压 ＋ 30"
  有 3 倍余量，安全。

## 6. 结论：两份清单

**给硬件验收的标准：**

| 项目 | 判据 |
|---|---|
| 全链噪声（传感器＋电路＋电源） | σ ≤ 0.1 mmHg 合格，设计目标 ≤ 0.05；≥ 0.2 进入警戒 |
| 心跳振荡幅度 | ≥ 1.5 mmHg 安全工作，< 1.3 起有风险 |
| 放气速率 | 目标 2–4 mmHg/s，不要 5 |
| 预充规则 | "上次收缩压 ＋ 30"余量充足 |
| 量化精度 | 0.1 mmHg 绰绰有余，不是瓶颈 |

**给后续工作的清单（真机数据到位后）：**

- 唯一必须重新定值的参数是"心跳幅度门槛"（它取决于真实噪声大小）；平滑窗口
  复核一下即可；其余 7 个参数不用再碰。
- 真机校准要吸收的主要就是实验四那种"个体形状差异"——预计收缩压 ±5 mmHg、
  舒张压更大的散布，与文献里"比率法固有 ±8–10 mmHg"的说法量级一致，属正常、
  可校准的范围。

## 7. 这组实验没覆盖什么

- **真实运动伪影**（晃动手臂、说话、碰袖带）没有建模，本实验的"抗噪声"结论
  只对白噪声和呼吸成立。真机上需要用实测伪影复核"不判废"这个特性。
- 仿真器仍然只有一个"标准人"，个体差异是用人为偏离来模拟的，不是随机人群。
  等真机数据或后续升级后再补齐。

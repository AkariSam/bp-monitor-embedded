# peaks.py —— 逐搏峰检测与有效性

> 代码：`bp/peaks.py`；规格：技术计划 §4.3（双门限滞回 + 动态阈值 + 三层有效性）。

## 1. 原理

### 1.1 双门限滞回状态机（GCY 机制）

状态机跟踪运行极大/极小；"梯度" `grad` 决定峰谷切换所需的**最小起伏**：

```
SEEK_PEAK:   v > max          → 更新 max（记住位置）
             v < max − grad   → 确认峰（位置 = max 处），转入 SEEK_TROUGH
SEEK_TROUGH: v < min          → 更新 min
             v > min + grad   → 确认谷，prev_trough = min，转入 SEEK_PEAK
```

每搏 = 一个峰 + 一个谷。峰确认天然滞后 ~半拍（因果，固件可流式执行）。
重搏波：峰后小波峰与主峰相距 ~0.15–0.25 s，被峰距门（<300 ms）剔除。

### 1.2 动态梯度：从 GCY 到本项目的归约（重要偏离）

GCY 原文：`th = dc × (CV%/100) × 3`，且 CV = sd/mean×100。在 GCY 的
ADC 基线域中 mean ≈ dc（AC 骑在基线上），**dc 与 mean 相消 → th = 3×sd**
（该块的标准差）。CV>50 时取 `th = dc`（≈冻结检测）。

我们的 AC 是 mmHg 零均值带通信号，直接归约得 `grad = k_grad × 块标准差`。
但**k_grad 不能取 3**——数学上滞回将无法切换：正弦 σ = A/√2，
3σ = 2.12A > 峰谷差 2A，信号永远够不到 `max − grad`。故取 **k_grad = 1.0**：

```
grad(块 k) = max(1.0 × std(块 k−1), grad_min)     # 因果：用上一块统计
```

- `grad_min = 0.5 mmHg`：仿真标定（噪声 σ≈0.05 → 需 10σ 级事件才能误触发；
  比值交叉点幅度 ≈1.06/1.48 ≫ 0.5，检测覆盖不受影响）。
- 块长 `grad_block_s = 1.25 s`（GCY 100 采样 @ 其采样率），按 fs 折算。

### 1.3 CV>50 噪声门：在本域被证明无区分度（实测）

仿真实测（normal 场景，100 采样块 |AC| 变异系数）：

| 区域 | std | CV(|AC|) |
|---|---|---|
| 干净静默区（Pc 180→145） | 0.02–0.08 | 24–83% |
| 干净脉搏区（Pc 145→85） | 0.07–0.53 | 60–110% |

**两类区域 CV 完全重叠**——GCY 公式的基线相对性在零均值域失效。
故本项目以三层防御替代 CV 门：**梯度下限 ＋ 相对 prominence ＋
邻搏一致性**（即 §1.2 的梯度下限与 §1.4 的后两层）。真实数据到位后
复核是否需引入运动段专用门（如短时高频能量比）。

### 1.4 三层有效性

按时间顺序执行，前两层因果，第三层用中心邻窗：

1. **峰距**：与上一通过项 < 300 ms → 剔除（双峰/重搏/毛刺）。
   上限 1.5 s **只作 HR 窗参考、不硬剔**——偏离规格的工程决策：
   硬剔会在漏搏后连锁误删（bradycardia 场景 RR=1.5 s 恰在边界），
   HR 用中位数天然抗离群。
2. **prominence**：`prom = 峰 − 前谷`；
   `prom < 0.25 × 近期通过项的中位数` 剔除（窗口 10、启用前 3 拍不判）。
   注：规格写"均值"，实现取**中位数**抗 bootstrap 污染，量级一致。
3. **邻搏一致性（Lim 2015）**：与前后各 ≤1 个通过项的幅度中位偏差
   >50% 判离群。**中心窗**是关键修正：早期顺序式参考窗（vs 冻结的历史
   均值）会把包络爬升段整段误判为离群（实测 20/24 被误剔）；中心窗
   中值跟随单调趋势，只抓突变尖峰（有专项回归测试）。
   中心窗需 ~1 搏延迟，固件用小型环形缓冲（≤4 搏）即可，内存有界。

bootstrap：前 3 个候选不做 prominence/Lim 门控（参考窗不足）；grad_min
足够高使其在实践中几乎只放行真实搏动（noise-only 回归测试：0 误检）。

## 2. 参数表

| 字段 | 默认 | 说明 |
|---|---|---|
| `grad_block_s` | 1.25 s | 块统计时长（因果，用上一块） |
| `grad_factor` | 1.0 | 梯度 = factor × 块标准差（GCY 归约，见 §1.2） |
| `grad_min` | 0.5 mmHg | 梯度下限（防噪底误检） |
| `prom_ratio` / `prom_ref_n` / `prom_arm_n` | 0.25 / 10 / 3 | prominence 门 |
| `rr_min_s` / `rr_max_s` | 0.3 / 1.5 | 峰距门（上限为软约束） |
| `lim_dev` / `lim_nbr` / `lim_nbr_min` | 0.5 / 1 / 2 | 邻搏门（中心窗 ±1） |

## 4. 实测（seed=1）

- normal：候选 24 / 接受 24，包络形状干净（prom 0.47→2.44@Pc100→0.68）。
- bradycardia：修复中心窗与边界窗后 SBP 误差 +12.9 → +4.2 mmHg。
- noise-only（σ=0.05，20 s）：0 误检。
- 尖峰注入回归：孤立 3.0 搏在 1.4 搏序列中被剔，链条不中断。

## 5. 已知简化 / 偏离

1. **k_grad=1.0 与 CV 门替代**（§1.2–1.3）：GCY 原值 3 在本域不可用，
   原因与实测已论证；待真实数据回归。
2. 峰距上限软约束（§1.4-1）。
3. prom 用中位替代均值；Lim 用中心窗（需小延迟缓冲）。
4. 运动伪影专项门控未实现（仿真未建模，见 sim/artifacts.md §5 清单）。

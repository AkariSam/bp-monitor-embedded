# envelope.py —— 逐搏包络构建

> 代码：`bp/envelope.py`；规格：技术计划 §4.3（每搏记录 {袖带压×10, 振幅×100}，
> 包络 ≤80 点；3 点中值 + 3 点滑动平均；<8 点判废）。

## 1. 原理

示波法包络 = **振幅 A 对袖带压 Pc 的曲线**（钟形，峰 ≈ MAP）。构建分两步：

### 1.1 逐搏对 (Pc, A)（`from_peaks`）

- **Pc = 峰时刻的对齐 DC 值**（逐点取值）。
  不用"窗口均值"的原因：首/末搏的窗口会被边界拉大（曾出现首搏窗口横跨
  16 s、Pc 被拉高到 153 mmHg 的伪点，直接毁掉 SBP 交叉），逐点取值无此病。
- **A = 搏动中点窗内 AC 峰峰值**（ptp）：
  内点窗 = [mid(i−1,i), mid(i,i+1)]；首/末搏向两侧只取**半个 RR** 的对称窗
  （不多吃空白区）。ptp 口径与可视化粗包络一致。
- prom（峰有效性指标）与 A（包络值）**用途分离**：prom = 峰−前谷用于门控，
  ptp 用于包络——两者量级相近但定义不同，不可混用。

### 1.2 排序与平滑（`build` + `smooth`）

- 按 Pc 升序排序（放气方向统一；固件 int16 {P×10, A×100} 同序）。
- **3 点中值**去毛刺（孤立离群点）→ **3 点滑动平均**磨平台阶；
  边缘用复制模式（与固件约定一致）。
- 点数 <8 的判废在 qc 模块（本模块不抛错，只构造）。

## 2. 参数表

| 字段 | 默认 | 说明 |
|---|---|---|
| `env_median` | 3 | 中值窗 [点] |
| `env_ma` | 3 | 滑动平均窗 [点] |
| `env_min_points` | 8 | 判废下限（qc 使用） |

## 3. 实现映射

| 函数 | 职责 |
|---|---|
| `from_peaks(dc, ac, peaks)` | 有效峰 → (pc, amp) 逐搏对 |
| `smooth(amp, median_w, ma_w)` | 中值 + 滑动平均 |
| `build(pc, amp, params)` | 排序 + 平滑 → `Envelope` |
| `Envelope` | frozen dataclass：pc / amp / amp_s / n_points |

## 4. 实测（seed=1）

- normal：29 点，逐搏包络峰 ≈1.9 mmHg @ Pc≈96（与模型锚定一致）。
- 平滑对孤立尖峰的抑制有专项单测（10× 尖峰 → 残差 <40%）。

## 5. 已知简化 / 偏离

1. 排序后相邻点 Pc 间距不均匀（≈2.5–4.5 mmHg），平滑与插值均按实际
   坐标处理，无等距假设。
2. 首/末搏半 RR 对称窗是工程折中（真实边界信息不足），对交叉点无影响
   （交叉位于包络中段）。
3. 包络点数上限 80（§4.3 规格）未显式截断：实测自然 ≤68（tachycardia），
   真实数据若超限需补截断策略。

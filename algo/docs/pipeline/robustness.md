# 参数扫描与健壮性实验（sweep.py）

> 对应代码：`algo/scripts/sweep.py`（四模式）；结果 JSON：`out/eval/sweep_*.json`；
> 图：`out/figs/sweep_*.png`（均可再生，不入库）。
> 一轮完整运行：2026-10-11，约 2600 次管线运行（含数据生成），全量约 10 分钟。
> 通俗版（非技术向，汇报可用）：[robustness_explained.md](robustness_explained.md)。

## 1. 目的与红线

回答五个问题：① 20+ 个算法参数里哪些碰不得、哪些脆弱？② 伪影压力多大时管线
开始坏（→ 硬件 E1/E5 验收判据）？③ 比率换算率的实现与文献是否一致？
④ 仿真器生理参数偏离锚点时误差多大（T7 个体差异预演）？⑤ 机动参数（预充、
放气速率）有什么系统约束？

红线（与实验计划一致，不可动摇）：

- **只测量、不修改任何默认值**——本实验的产物是结论与判据，不是新的参数值；
- **比率 0.50/0.70 不做寻优**（仿真器已对齐，扫它只为验证实现）；
- 真值只在脚本层读取，`bp/` 与 `sim/` 均不接触。

## 2. 方法

四个实验（`--mode`）的总览：

| 实验 | 模式 | 变量 | 场景×种子 | 规模 |
|---|---|---|---|---|
| 一 算法参数敏感性 | `algo` | 10 个 AlgoParams 参数，一次动一个（OAT） | 8×3 | 650 次管线 |
| 二 伪影压力扫描 | `stress` | 白噪声/呼吸/抖动/速率/工频/最坏组合 | 8×5 | 760 次生成+管线 |
| 三 比率换算率验证 | `ratio` | ratio_sbp 0.40–0.60、ratio_dbp 0.60–0.80（步 0.02） | 8×3 | 包络复用，仅重跑判定 |
| 四 仿真器参数 | `sim` | 形状（σn/σp/μ）/幅度尺度/量化/速率×心率/预充 | 1–2×3 | 190 次生成+管线 |

判定口径：

- **实验一**：每档相对基准的最大读数变化 maxΔ（SBP/DBP/HR）、接受翻转（误拒=基准
  接受而该档判废；误收=基准判废而该档接受，truncated 场景的安全线）；
  分级：**钉死**（maxΔ<0.5 mmHg 且无翻转）→ 以后不再花精力；**观察**（0.5–2 或个别
  翻转）；**脆弱**（≥2 mmHg、≥3 误拒、或出现误收）。
- **实验二**：断点 = 接受率 <0.8 或 MAE >2 mmHg 的第一档。
- 中断档位口径：速率×心率取 normal 血压、PP=40；预充扫描 PP=40（臂围/耦合对
  高压侧余量的影响另有说明）。

复现：

```bash
cd algo           # 先激活 .venv
python scripts/sweep.py --mode algo    # 依次四个模式；各约 1–5 分钟
python scripts/sweep.py --mode stress
python scripts/sweep.py --mode ratio
python scripts/sweep.py --mode sim
```

## 3. 结果

### 3.1 实验一：算法参数敏感性（8 场景 × 3 种子）

基准：21/24 接受（truncated×3 按设计判废），MAE 0.588 / 0.943 mmHg。

| 参数 | 默认 | 扫描档位 | maxΔ SBP/DBP | maxΔ HR | 误拒/误收 | 判定 |
|---|---|---|---|---|---|---|
| `grad_min` | 0.5 | 0.25–1.0 | 1.25 / 0.00 | 1.99 | 22 / 0 | **脆弱** |
| `prom_ratio` | 0.25 | 0.10–0.50 | 0.00 / 0.00 | 0.56 | 0 / 0 | 钉死 |
| `env_median` | 3 | 1 / 3 / 5 | 1.57 / 1.79 | 0 | 1 / 0 | 观察 |
| `env_ma` | 3 | 1 / 3 / 5 | 1.80 / 2.99 | 0 | 1 / 0 | **脆弱** |
| `edge_margin_s` | 0.5 | 0.25–1.0 | 0.00 | 0 | 0 / 0 | 钉死 |
| `grad_factor` | 1.0 | 0.5–2.0 | 0.00 | 0 | 0 / 0 | 钉死 |
| `grad_block_s` | 1.25 | 0.6–2.5 | 0.00 | 0 | 0 / 0 | 钉死 |
| `prom_ref_n` | 10 | 5–20 | 0.00 | 0 | 0 / 0 | 钉死 |
| `prom_arm_n` | 3 | 1–5 | 0.00 | 0 | 0 / 0 | 钉死 |
| `lim_dev` | 0.5 | 0.3–0.7 | 0.34 / 0.00 | 0 | 0 / 0 | 钉死 |

细读（图：`sweep_algo.png`）：

- **7/10 参数在宽范围内零差别**（部分严格为 0）——固件移植的实现容差很大，
  `grad_factor`、`grad_block_s`、`prom_*`、`lim_dev`、`edge_margin_s` 不必再花精力。
- **`grad_min` 是唯一的高危参数，且风险方向朝上**：0.75 起误拒（brady×2 + tachy），
  1.0 时 19/24 误拒（几乎全灭）；0.25 侧只带来 1.2 mmHg 级变化。结合 3.4b 的
  幅度悬崖：**它是唯一必须用真机噪声实测重新定值的参数**。
- **平滑强度有窄平台**：`env_ma=1`（不平滑）→ DBP 最大变化 2.99 mmHg；
  `env_ma=5` / `env_median=5` → brady 误拒 1 例。默认 3+3 恰在平台中间。
- `prom_ratio` 彻底钉死：0.10–0.50 之间输出逐位相同；强噪声交互探针（3.5）也确认
  零区分度。

### 3.2 实验二：伪影压力扫描（8 场景 × 5 种子）

稳态场景 MAE [mmHg]（SBP/DBP）：

| 变量 | 档位 → 结果（末档接受率） | 断点 |
|---|---|---|
| 白噪声 σ | 0.02→0.63/0.91 ｜ 0.05→0.89/1.02 ｜ 0.1→1.43/1.48 ｜ 0.2→2.61/2.43 ｜ 0.4→4.75/4.58（100%） | 0.2 |
| 呼吸幅度 | 0→0.57/0.77 ｜ 0.5→0.63/0.91 ｜ 1.0→1.47/1.29 ｜ 2.0→10.80/2.09（74%） | 2.0 |
| 心率抖动 | 0.1→0.52/0.88 ｜ 0.2→0.78/1.16 ｜ 0.3→0.84/1.11（100%） | — |
| 放气速率 | 2→0.60/0.69（55 点） ｜ 3→0.63/0.91（37 点） ｜ 5→0.78/1.56（86%） | — |
| 工频（50 Hz） | 开→0.76/0.95（vs 关 0.63/0.91） | — |
| 最坏组合 | 噪声0.2＋呼吸1.0＋速率5＋抖动0.2 → 5.98/4.08（97%） | — |

要点（图：`sweep_stress.png`）：

- **噪声是平滑降级，没有拒绝悬崖**：σ 从 0.02 加到 0.4（超过信号幅度 20%），
  接受率始终 100%，误差从 0.6 平滑涨到 4.7 mmHg。QC 的判废条件（包络粗糙度、
  离群占比）识别不了「噪声大但结构完好」的数据——这是记录在案的行为特性
  （真实运动伪影不服从白噪模型，见 §6 局限）。
- **E1 硬件判据（头号产出）**：全链噪声 σ ≤ 0.05 → 误差增量 ≤1.0 mmHg；
  σ ≤ 0.1 → ≤1.5 mmHg；σ ≥ 0.2 进入警戒区。验收建议：**实测噪声 σ ≤ 0.1 为合格，
  设计目标 ≤ 0.05**。
- 呼吸 ≤1.0 mmHg 安全；2.0（骑在 0.5 Hz 滤波边界上）会把 SBP 拖到 10.8 mmHg
  且 26% 判废——呼吸极重时管线给出偏高的 SBP 而不是判废，属已知风险。
- 抖动 ±30% 依然稳（中位数 RR 的作用）；工频混叠后几乎无影响。

### 3.3 实验三：比率换算率验证（包络复用，仅重跑判定）

| 侧 | 零点（汇总） | 零点（各场景） | 斜率 | 文献对照 |
|---|---|---|---|---|
| SBP（ratio_sbp） | 0.5105 | 0.493–0.518 | **−4.03 mmHg / 0.1** | 0.2 比率差 → 8 mmHg（=−4.0/0.1）完全吻合 |
| DBP（ratio_dbp） | 0.7096 | 0.68–0.72 | +5.53 mmHg / 0.1 | 方向正确；本模型低压侧更陡 |

结论：零点锚定在 0.50/0.70 附近（±0.02，即搏动网格插值精度），斜率量级与文献
一致——**比率法实现正确**，Flash 可调范围内行为可预测（图：`sweep_ratio.png`）。
汇总零点偏离 0.5/0.7 的 ~0.01 来自逐场景残差的合成口径，各场景单独看更接近锚点。

### 3.4 实验四：仿真器生理与机动参数

#### (a) 形状失配 → 误差映射（normal + wide_pp）

| 配置 | r_s | r_d | k | MAE SBP/DBP |
|---|---|---|---|---|
| 基准 | 0.500 | 0.700 | 0.410 | 0.64 / 0.69 |
| σn×0.7 / ×1.4 | 0.477 / 0.531 | ≈0.70 | 0.390 / 0.435 | 0.86 / 0.59 ｜ 2.21 / 0.75 |
| σp×0.7 / ×1.4 | 0.575 / 0.460 | 0.520 / 0.827 | 0.437 / 0.391 | 3.97 / **8.73** ｜ 2.03 / **14.12** |
| μ×0.7 / ×1.4 | 0.382 / 0.647 | 0.786 / 0.586 | 0.308 / 0.546 | 5.30 / 6.82 ｜ 7.88 / 7.84 |
| 全部×0.7 / ×1.4 | 0.421 / 0.633 | 0.653 / 0.747 | 0.308 / 0.546 | 3.24 / 2.34 ｜ 7.58 / 6.00 |

要点（图：`sweep_sim.png` 左上）：

- **DBP 侧对形状远比 SBP 侧敏感**：σp ±40% 使 r_d 偏离锚点 0.13–0.18，
  DBP 误差直达 8.7–14.1 mmHg；SBP 同幅度偏离只有 2–4。
- μ 与 σp 的变化同时移动 r_s、r_d、k，是「全身形状」的搬运工。
- 量化换算（与 3.3 斜率一致）：边界比率每偏 0.01 ≈ SBP 0.5 / DBP 0.55 mmHg。
- **T7 预演**：文献个体 r_s 散布 SD≈0.11（Amoore 0.49±0.11）对应本管线
  SBP ±5 mmHg 量级、DBP 更大——固定 0.50/0.70 的个体间误差就是校准要吃掉的东西，
  与研究报告里「比率法固有 ±8–10 mmHg」的说法量级一致。

#### (b) 幅度尺度与量化

| 配置 | Amax [mmHg] | MAE SBP/DBP | 接受率 |
|---|---|---|---|
| 基准（k_cuff=20） | 1.92 | 0.96/1.25 | 100% |
| k_cuff=10 | 3.83 | 0.88/0.64 | 100% |
| k_cuff=40 | 0.96 | — | **0%** |
| LSB=0.05 / 0.2 | 1.92 | ≤1.26 | 100% |

补充探针（机制确认，normal + brady，3 种子）：

- Amax≈1.53（k=25）全过；**1.28（k=30）brady 1/3**；1.10（k=35）normal 2/3、
  brady 0/3；0.96（k=40）全灭。
- 把 `grad_min` 从 0.5 降到 0.25，Amax=0.96 立刻恢复 3/3——**机理确认**：绝对门限
  `grad_min` 相对弱信号过高，切掉了包络两侧的尾点，SBP 交叉找不到。

结论：**峰幅工作下限 ≈1.3–1.5 mmHg（grad_min=0.5 时）**；设计值 Amax≈2 只有约
1.4× 余量。胖臂/松袖带/低脉压的弱耦合患者是风险源；固件后续可考虑 grad_min
自适应（按块幅度缩放）。量化 LSB 0.05–0.2 对误差影响 ≤0.4 mmHg——**E1 的
「分辨率 ≤0.1」不是瓶颈项**。

#### (c) 放气速率 × 心率（normal 血压）

误差 SBP/DBP 与接受率（图：`sweep_sim.png` 左下）：

| 速率 \ 心率 | 40 | 70 | 110 | 180 |
|---|---|---|---|---|
| 2 mmHg/s | +1.0/−1.0（24 搏） | ≈0（45 搏） | ≈0（67 搏） | ≈0（100 搏） |
| 3 mmHg/s | +1.5/−2.0（16 搏） | +0.4/−0.1 | +0.3/−0.0 | +0.2/+0.6 |
| 5 mmHg/s | **判废**（9–10 搏） | +0.8/−1.8（17 搏） | +0.3/−1.1 | ≈0 |

要点：

- 慢心率 + 快放气 = 每搏步长 `RR × 速率` 变粗（40 bpm、5 mmHg/s 时 7.5 mmHg/搏），
  误差项随之增大；**40 bpm + 5 mmHg/s 直接判废**（9–10 搏且高压侧不足以找到
  SBP 交叉，逐种子复现）。
- E3 气路决策门建议：**目标自然漏气 2–4 mmHg/s**；若实测压不下来，宁加装备用慢阀，
  不要接受 5 mmHg/s 作为规格（会牺牲慢心率人群）。

#### (d) 预充充裕度（PP=40）

- 网格 10–40 mmHg 余量全部 20 格 OK（SBP 90–190）。
- 补充探针：**余量 0 全灭；余量 5 处于边界**（SBP90 过 3/3、SBP120/190 败）。
- 机理：锚定形状下 r_s=0.50 的交叉点恰好落在 SBP 处，需要的高压侧余量主要是
  「交叉点两侧各几个逐搏点」的插值需求。

结论：**最低充足余量 ≈10 mmHg**；固件「上次 SBP+30（封顶 240）」≈3× 安全余量，
规则保留。10 是本模型（PP=40、锚定形状）的判据；个体 r_s 散布（±0.11）会把交叉
点相对 SBP 挪 ±5–6 mmHg 量级，30 的余量仍充裕。

### 3.5 交互与补充探针汇总

| 探针 | 结果 | 去向 |
|---|---|---|
| `prom_ratio` × 强噪声（0.2+呼吸1.0） | 0.10 / 0.25 / 0.50 三档 MAE 5.49/2.94、5.49/2.94、5.49/2.98——零区分度 | `prom_ratio` 钉死维持 |
| `grad_min` × 弱信号 | 3.4b：门限是弱幅度失败的直接原因 | 真机重定值的第一优先参数 |
| rate5 × hr40 判废机理 | 9–10 搏 + 高压侧不足 → 「SBP 交叉未找到」 | E3 规格建议 |

## 4. 结论

**参数分级名单**（真机数据到位后按此顺序重看）：

| 级别 | 参数 | 说明 |
|---|---|---|
| 脆弱（真机重定值） | `grad_min` | 绑定传感器噪声与信号幅度，唯一必须有真机数据才敢定值的参数 |
| 观察（真机复核） | `env_ma`、`env_median` | 平台存在但有边缘（1 侧 DBP 抖动、5 侧 brady 误拒）；真包络噪声形态待验 |
| 钉死（不再花精力） | `prom_ratio`、`edge_margin_s`、`grad_factor`、`grad_block_s`、`prom_ref_n`、`prom_arm_n`、`lim_dev` | 宽档位零差别（双实验） |
| 锚定（不动） | `ratio_sbp/dbp`、频带、HR 窗 | 只能真机标定；实现已验证 |

**硬件判据汇总**（喂 E1/E3/E5 验收）：

| 项 | 判据 |
|---|---|
| 全链噪声（传感器+ADC+电源） | σ ≤ 0.1 mmHg 合格（目标 ≤0.05）；σ≥0.2 警戒 |
| 振荡峰幅 | ≥1.5 mmHg 工作区；<1.3 起风险（grad_min=0.5 时） |
| 放气速率（E3） | 目标 2–4 mmHg/s；5 mmHg/s 牺牲 40 bpm 人群 |
| 预充规则 | 「上次 SBP+30」充足（≥3× 余量）；最低充足 ≈10 |
| 量化 | LSB 0.1 非瓶颈，0.2 也仅 ≤0.4 mmHg 代价 |

**红线重申**：本轮未改任何默认值；0.50/0.70 保持；校准系数继续留给真机
（`calibrate.py` 意义见 3.4a）。

## 5. 已知局限

- 运动伪影与泵阀瞬态未建模（docs/sim/artifacts.md §5 搁置项）——本实验的
  「噪声韧性」结论只对白噪声+呼吸成立，不覆盖真实伪影；QC 对重度噪声不判废的
  特性在真机上需用伪影复核。
- 仿真器仍是「单一形状个体」：3.4a 用系统性偏离模拟人群散布，未引入随机分布
  （仍在搁置清单）。
- 压力扫描的种子数（5）足以看趋势，不构成统计置信区间。

## 6. 文档-代码锚点

- 参数默认值唯一来源：`bp/params.py`；本实验的全部档位可在 `scripts/sweep.py`
  的 `ALGO_GRID` / `STRESS_SERIES` / `WORST_COMBO` / `_sim_*` 常量中追溯。
- 仿真器覆盖入口（`generate` 的 `physio`/`art`/`lsb` 覆盖参数）为 sweep 新增，
  默认调用行为不变（同 seed 字节级复现契约未动）。
- 后续改动：若真机数据导致任一参数重定值，必须同步更新本篇 §4 名单与
  `docs/pipeline/README.md` 的状态行。

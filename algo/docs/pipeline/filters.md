# filters.py —— 数字滤波与时基对齐

> 代码：`bp/filters.py`；规格：技术计划 §4.2。

## 1. 原理

### 1.1 两路分离

袖带压原始序列 `p_raw` 同时含**袖带静压**（DC，放气斜坡 180→40 mmHg）与
**脉搏振荡**（AC，1–3 mmHg，≈DC 的 1/1000）。两路滤波：

| 路 | 设计 | 保留内容 | 阻断内容 |
|---|---|---|---|
| DC | 2 阶 IIR 低通 0.5 Hz | 放气斜坡（主频 ≪0.1 Hz） | 脉搏（≥0.67 Hz） |
| AC | 2 阶高通 0.5 Hz ＋ 2 阶低通 8 Hz 级联 | 脉搏基频（0.67–3 Hz）＋谐波至 ~8 Hz | 呼吸/漂移（<0.5），高频噪声（>8） |

AC 带通截止与文献信号带一致（0.5–8 Hz），四阶 = 两段 biquad 级联，与固件
biquad 实现一一对应。

### 1.2 因果滤波 + 稳态初始化

- 固件是因果实时系统，PC 端**不用 filtfilt**（零相位会掩盖移植时的相位问题）。
- 因果 sosfilt 从零状态启动时，0.5 Hz 低切滤波器对"0→180 mmHg 跳变"的暂态
  会残留数毫米汞柱级假振荡。解法：`sosfilt_zi` 按首样本构造稳态初值——
  首样本 ≈ 恒定压力，由此启动暂态近似为零（实测 `test_startup_transient_suppressed`）。

### 1.3 时基对齐：群延迟 ≠ 相位延迟（重要）

滤波后信号相对真实时刻有延迟，必须补偿（agata 83 采样未补偿 → 包络错位教训）。
但对 **IIR**，两种"延迟"含义不同，需分路对待：

- **DC 路用群延迟**：放气斜坡是慢变包络，延迟 = 低频群延迟
  ≈ 1.414/(2π·0.5 Hz) ≈ 0.45 s ≈ **36 采样**（数值测量 `group_delay_samples`）。
- **AC 路用相位延迟**：峰的移动量由**基频处的相位**决定。2 阶高通在
  1.2 Hz（HR≈72 基频）处相位**超前** +35°（高通段），低通段滞后仅 ~17°，
  净超前 → 相位延迟 ≈ **−3.3 采样**（负号 = 超前！）。
  若误用群延迟（9.4 采样）补偿，峰会对齐到错误时刻，方向还反了。

```
相位延迟 = −φ(ω_ref)/ω_ref     [采样]（正 = 滞后，负 = 超前）
群延迟   = −dφ/dω                [采样]（斜坡时基用）
```

两者都用 `sosfreqz` 在参考频率邻域 5 点数值测量（解卷绕 + 局部拟合）。

## 2. 公式与参数

- 设计：`butter(order, cut, btype, fs, output="sos")`；AC = `vstack(hp_sos, lp_sos)`。
- 补偿：`compensate(x, d)` 左移 d 采样（d<0 右移），移出端补零。
- 参考频率：DC 0.1 Hz、AC 1.2 Hz。

| AlgoParams 字段 | 默认 | 说明 |
|---|---|---|
| `dc_order` / `dc_cut_hz` | 2 / 0.5 | DC 低通 |
| `ac_hp_order` / `ac_hp_hz` | 2 / 0.5 | AC 高通 |
| `ac_lp_order` / `ac_lp_hz` | 2 / 8.0 | AC 低通 |
| `gd_dc_ref_hz` / `gd_ac_ref_hz` | 0.1 / 1.2 | 群延迟/相位延迟参考频率 |
| `edge_margin_s` | 0.5 | DEFLATE 切片两端分析余量 |

## 3. 实现映射

| 函数 | 职责 |
|---|---|
| `design_dc(params)` / `design_ac(params)` | butter → sos |
| `causal_filter(sos, x)` | 因果 sosfilt + 首样本稳态初始化 |
| `group_delay_samples(sos, fs, f)` | 群延迟测量（DC 用） |
| `phase_delay_samples(sos, fs, f)` | 相位延迟测量（AC 用） |
| `compensate(x, d)` | 时基对齐移位 |
| `filter_dc_ac(p, params)` | 一站式：(dc, ac) |

## 4. 实测

- 正弦 1.2 Hz 实测峰滞后 −4 采样（与相位延迟理论 −3.3 一致）；补偿后
  对齐误差 ≤1 采样（`test_ac_compensation_aligns_sine`）。
- DC 斜坡补偿后 94 s 处误差 <0.2 mmHg（`test_dc_compensation_aligns_ramp`）。

## 5. 已知简化 / 偏离

1. **AC 参考频率固定 1.2 Hz**，未随实测 HR 自适应：HR 40–180 时基频
   0.67–3.0 Hz，相位延迟差异按采样级计（≤数采样 ≈0.1 mmHg 级），
   留给真实数据评估；固件可在测到 HR 后二次修正。
2. **DC/AC 均为 IIR 非线性相位**，波形形状会变（agata 教训的另一面）；
   我们只取峰/包络特征，规避形状依赖。
3. 参考频率处测量为线性近似，宽带信号的实际峰移存在二阶残差（同上量级）。

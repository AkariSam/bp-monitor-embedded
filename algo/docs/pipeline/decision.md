# decision.py —— SBP/DBP/HR 判定与校验

> 代码：`bp/decision.py`；规格：技术计划 §4.4（比率法 + DIA 交叉校验 + IPP）。

## 1. 原理

### 1.1 MAP 与比率交叉

```
MAP = 包络最大振幅处的压力      （3 点抛物线顶点细化）
SBP = 从 MAP 向高压侧，首次跌到 0.50 × Amax 处的压力（线性插值）
DBP = 从 MAP 向低压侧，首次跌到 0.70 × Amax 处的压力（线性插值）
```

- "从 MAP 向外找**首次**交点"：多交点（噪声）时天然取最靠近 MAP 的稳健
  交点，避免远尾假交叉。
- 比率初值 0.50/0.70 出自综述共识（Geddes/Sharman/Amoore）；
  **口径纪律**：不引用未证实的 0.55/0.85。Flash 可调范围 0.40–0.65 /
  0.60–0.85，真机标定（T1/T2）时改动。
- MAP 细化：规格写"线性插值加密"；线性插值对 argmax 无增益，本实现用
  3 点抛物线顶点（等效"加密"意图，已记录为偏离）。

### 1.2 DIA 交叉校验

```
DIA_formula = (3×MAP − SBP) / 2
|DBP − DIA_formula| > 10 mmHg → 质量标志（公式法系统性偏高，不作结果值）
```

公式隐含旧 MAP 模型 M≈(S+2D)/3；本仿真/管线 M=0.41S+0.59D → 偏差
≈0.115×PP（大脉压场景可逼近 10 mmHg 容差，属公式局限的预期行为，见 §2）。

### 1.3 HR 与节律

- `HR = 60 / median(峰间期)`——中位数抗离群（漏搏/伪峰产生的长间期）。
- **量化下限**（实测发现）：fs=80 时 RR 量化 12.5 ms，HR 180 bpm 处
  1 采样 ≈ 3.75 bpm；中位数在 RR=26.67 采样处给出 177.8（−2.2 bpm）。
  属采样率物理下限，E1 选更高 fs 的传感器模组可缓解。
- **IPP（GCY 法）**：逐间期 `|rr − median|/median > 0.2` 记 1 次不规则；
  不规则占比 > 0.2 → 附「疑似心律不齐」标志（仅提示，不作诊断）。
  与 GCY 源码对照：原版用**均值 HR 域**（|1 − HR_i/HR_mean|>0.2），
  本实现用 RR 域中位（稳健版，数值同量级）。
- **敏感性观察（sim 实测）**：jitter=0.2 的 af 场景，判据对单次实现敏感
  （5 seed 中 2 个触发；分析窗内 rr 实现本身波动大）。集成测试采用
  "多 seed 至少一次触发"；真实 AF 数据到位后需重新标定该判据。

## 2. 端到端修正实测（seed=1，对仿真真值）

仿真形状已于 2026-10-04 锚定到管线常数（r_s=0.50 / r_d=0.70 / k=0.41，
见 docs/sim/model.md §5.1），系统性偏移消除，残余主要为**搏动网格离散**
（步长 = RR×放气速率）：

| 场景 | SBP err | DBP err | 备注 |
|---|---|---|---|
| normal | +0.3 | +0.2 | |
| hypertension | −0.1 | −0.6 | DIA 校验旗标（见下） |
| hypotension | +0.0 | −0.8 | |
| wide_pp | +0.7 | +0.8 | DIA 校验旗标 |
| af | +0.5 | +1.3 | |
| bradycardia | +1.1 | −2.0 | 搏动网格最粗（HR40，4.5 mmHg/搏） |
| tachycardia | +0.2 | +0.5 | |

残余 ≤2.0 mmHg；集成测试容差 ±3（tests/test_pipeline_integration.py）。
**DIA 交叉校验旗标**是公式局限的预期行为：`(3M−S)/2` 隐含 M≈(S+2D)/3，
本模型 M=0.41S+0.59D → 偏差 ≈0.115×PP（hypertension 10.1、wide_pp
12.1 mmHg，跨过 10 mmHg 容差）；仅质量旗标，不判废、不作结果值。

> 历史：2026-10-01 搏内调制修正消除约定差 +0.7~+1.7 mmHg；
> 2026-10-04 形状锚定将一边倒偏差从 +2.0~+7.5 收敛到 ≤2.0（MAE 0.4/0.9）。

## 3. 参数表

| 字段 | 默认 | 说明 |
|---|---|---|
| `ratio_sbp` / `ratio_dbp` | 0.50 / 0.70 | 比率（Flash 可调） |
| `dia_tol` | 10 mmHg | DIA 校验容差 |
| `ipp_thr` / `ipp_ratio_thr` | 0.2 / 0.2 | IPP 逐拍/占比阈值 |
| `hr_min` / `hr_max` | 40 / 180 | HR 有效窗（越窗打标志） |

## 4. 实现映射

| 函数 | 职责 |
|---|---|
| `decide(env, peak_times, params)` | 总入口 → `Decision` |

| `Decision` | frozen dataclass：map/sbp/dbp/hr/dia_*/ipp/arrhythmia/reasons |

## 5. 已知简化 / 偏离

1. MAP 抛物线细化替代"线性插值加密"（§1.1）。
2. HR 中位数在 fs=80 的量化下限（§1.3）；不做均值/插值修正。
3. IPP 用 RR 中位域（GCY 为 HR 均值域）；单实现敏感性已记录（§1.3）。
4. 比率固定值未做脉压/硬度自适应（规格如此；标定阶段再评估）。

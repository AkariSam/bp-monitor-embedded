# PC ↔ 固件对拍与 float32 敏感性报告（S3/S4）

日期：2026-10-24
范围：`firmware/algo` + `firmware/analyzer.py` 的 Python 参考实现，对拍对象为
`algo/bp`（PC 正本）。`algo/` 未做任何修改。

## 1. 对拍口径

| 口径 | 输入 | 说明 |
|---|---|---|
| PC 原始 | `algo/data/sim/<scene>_s001.csv` | 80 Hz、`t_ms` 为 12.5 ms 浮点网格，PC 正本 `bp.pipeline.run` |
| PC 同缓冲 | 固件 `DeflateBuffer` | `t` 取整数毫秒、`p` 取 0.01 mmHg，逐样本与固件 `_ScaledArray` 完全同输入 |
| 固件 | 同一 `DeflateBuffer` | `PipelineAnalyzer` 分阶段执行滤波 → 峰检测 → 包络 → 判定 → QC |

严格移植等价性以 **PC 同缓冲 vs 固件** 判定；**PC 原始 vs 固件** 对应任务交付口径，
其差异主要来自 CSV 的 12.5 ms 浮点时间被设备时基取整为 1 ms。

## 3. S4：float32 敏感性

注入方式：`firmware/algo/{filters,peaks,envelope,decision,qc}.py` 均带默认关闭的
`set_quantizer()` 钩子。测试用 `struct.pack("<f")` 对每一步中间量做 binary32
往返，再以 float64 存储计算。这不是逐指令单精度乘加模拟，但对滤波器系数/状态、
稳态初始化、延迟估计、包络、判定插值与 QC 算术做了逐操作舍入压力测试。
S5 整改后分析器工作区已使用 `array('f')`，下表“基线”指
`array('f')` 存储 + float64 算术；极点/zi/延迟三行仍是纯 float64 设计函数
对比 f32 设计函数。

| 风险点 | 基线 | float32 钩子 | 判据 | 结论 |
|---|---|---|---|---|
| AC 高通极点漂移 | `r=0.972613970819`，`angle=0.027775156` | `r=0.972613965690`，`angle=0.027774604` | 半径相对漂移 `<1e-6`，角度漂移 `<1e-5` | 通过（`5.27e-9` / `5.52e-7`） |
| AC 低通极点漂移 | `r=0.642496379831`，`angle=0.474581583` | `r=0.642496376287`，`angle=0.474581651` | 同上 | 通过（`5.52e-9` / `6.79e-8`） |
| DC `sosfilt_zi` 大数相消 | `z0=0.99962493038367994`，`z1=-0.94560286661596238` | `z0=0.99964457750320435`，`z1=-0.94562149047851562` | 相对误差 `<1e-4` | 通过（`1.97e-5`）；初始偏差约 `3.5e-3 mmHg`，经 0.5 s 余量衰减到 `1e-3 mmHg` 量级 |
| 群延迟取整 | `gd_dc=37.389257`，取整 37 | `gd_dc=37.413723`，取整 37 | 两者取整相同且距 37.5 边界 `>0.05` 采样 | 通过（边界余量 `0.111` 采样） |
| 相位延迟取整 | `pd_ac=-4.375038`，取整 -4 | `pd_ac=-4.375032`，取整 -4 | 两者取整相同，漂移 `<0.01` 采样 | 通过（漂移 `6.06e-6`） |
| 边缘搏动接受/剔除 | 8 场景候选/接受峰索引 | 与基线逐项相同 | 变化数 = 0 | 通过（0/8 场景变化） |
| 整链 f32 输出 | `array('f')` 存储 + float64 算术 | `max ΔSBP=5.80e-3`，`max ΔDBP=8.35e-3 mmHg`，`max ΔHR=8.60e-6 bpm` | `≤0.1 mmHg / 0.1 bpm` | 通过；距 1 mmHg 判据约两个数量级 |
| 0.01 mmHg + 1 ms 输入量化耦合 | PC 原始 | PC 同缓冲 | SBP/DBP `≤1 mmHg`、HR `≤1 bpm` | 通过；压力路径无损（CSV 本身两位小数），HR 最大变化 `0.264 bpm` |

QC 结论在 float32 钩子、基线、PC 同缓冲三方向完全一致；truncated 仍以同一理由拒绝。

## 4. 最终判定

**通过**。8/8 场景 QC 结论一致，7 个接受场景 SBP/DBP 对拍误差在 `1e-4 mmHg`
量级（`array('f')` 工作区存储舍入）；float32 钩子注入下最大输出偏移
`8.35e-3 mmHg`、`8.6e-6 bpm`，峰检测与 QC 结论无任何变化。未发现需要整改的
数值风险点。

残余说明：本报告验证的是 Python 参考实现的数值敏感性，未在 RP2350 实机上做
逐指令单精度验证；上机后建议用同一 8 场景回放核对一次。f32 钩子默认关闭，
生产路径不引入量化。
